# Data-Professional-Survey-Dashboard
# 📊 Data Professional Survey Breakdown — Power BI Dashboard

An interactive Power BI dashboard analyzing survey responses from 630 data professionals, exploring salary trends, career satisfaction, skill preferences, and demographics across the data industry.

![Dashboard Preview](Screenshot2026-08-27134844.png)

## 🎯 Project Overview

This dashboard was built to answer a few key questions about people working in (or trying to break into) the data field:

- What do data professionals earn, and how does it vary by job title?
- How happy are people with their work/life balance and salary?
- Which countries and demographics are represented in the survey?
- What tools/languages do data professionals actually use and prefer?
- How difficult is it to break into the data industry, based on real responses?

## 🔍 Key Insights

- **630 survey takers**, average age **29.87 years**
- **Python** is the overwhelmingly preferred programming language, far ahead of R, JavaScript, C/C++, and Java
- **Data Analysts** reported the highest average salary among the job titles surveyed
- Only **42.7%** of respondents found breaking into data "neither easy nor difficult" — the rest found it notably harder or easier
- Average happiness score for **work/life balance: 5.74/10**
- Average happiness score for **salary: 4.27/10** — salary satisfaction trails work/life balance
- Gender split: **74.3% male, 25.7% female**
- Top represented countries: Canada, United States, United Kingdom, India, and others

## 🛠️ Tools & Techniques Used

- **Power BI Desktop** — data modeling and report design
- **DAX measures** — for average calculations (salary, happiness scores, age)
- Interactive **slicers** (Gender, Country) with cross-filtering enabled across all visuals
- Custom **treemap, donut, gauge, and pie visuals** for varied data storytelling
- Consistent color theming and layout alignment for a polished, presentation-ready dashboard

3. Explore the dashboard using the Gender/Country slicers, or click any chart to cross-filter the rest of the page
